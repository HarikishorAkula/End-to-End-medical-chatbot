
🏥 Medical RAG Chatbot – README Template
📌 Project Overview
This project is an intelligent Medical Chatbot that leverages Retrieval-Augmented Generation (RAG) with:

Pinecone for vector storage and semantic search

LangChain for orchestration

LLM (Gemini / OpenAI / Ollama) for conversational responses

It provides context-aware medical information by embedding medical PDFs, guidelines, and FAQs.

⚙️ Tech Stack
Python 3.10+

LangChain

Pinecone

LLM API (Gemini / OpenAI / Ollama)

Streamlit (for deployment)

pdfplumber / PyPDF2 (for PDF ingestion)
